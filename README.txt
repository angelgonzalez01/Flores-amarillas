# 🌻 Día de las Flores Amarillas

Sitio web local con una animación de flores amarillas que crecen y un mensaje de felicitación.

## Cómo ejecutarlo

1. Descomprime el archivo ZIP.
2. Abre la carpeta `proyecto_flores_amarillas`.
3. Haz doble clic en `index.html`.
4. Se abrirá en tu navegador.
5. Presiona **"Hacer florecer el jardín"** para volver a ejecutar la animación.

## Archivos

- `index.html` → estructura de la página.
- `style.css` → diseño, flores y animaciones.
- `script.js` → creación de flores, crecimiento y pétalos.

No necesita servidor ni instalación: funciona directamente de forma local.
